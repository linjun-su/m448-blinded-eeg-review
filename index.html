Case

True alarm: the emitted alarm falls 5–60 minutes before an annotated seizure onset.
False alarm: the emitted alarm falls outside every 5–60 minute prediction interval and is counted in valid operational background.
Protocol-excluded alarm: retained for waveform review, but not used as a third clinical class and not included in independent TP/FA scoring.
These are timing-based evaluation labels—not a claim that the displayed pre-alarm EEG itself contains a seizure.
